# KiCad Project Guidelines

## Core Principles

### Deep Thinking Requirement
- Before performing any operation, engage in deep and comprehensive thinking
- THINK HARD, THINK DEEP, THINK WIDE AND THINK COMPREHENSIVE
- Consider all implications, edge cases, and potential impacts before taking action
- Analyze thoroughly from multiple perspectives before making decisions

## Code Standards
- No Chinese characters should appear in any code
- All code must be ASCII-compliant unless specifically required otherwise

## Development Best Practices
- Always analyze existing code structure before modifications
- Maintain consistency with the existing codebase patterns
- Document significant changes and decisions
